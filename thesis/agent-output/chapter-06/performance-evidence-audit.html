2. Measurement Boundary

The sampler runs on the Minikube node, outside the measured monitor cgroup. It discovers cgroup-v1 paths for the monitor and target and reads their counters together with node /proc/stat.

MetricDefinitionPermitted interpretation
Monitor CPUdelta(cpuacct.usage) / delta(wall-clock ns) * 100CPU charged to the monitor container cgroup, expressed as a percentage of one core.
Target CPUSame cgroup formula for the target container.Workload context, not monitor overhead.
Node CPUBusy-time deltas from /proc/stat.Utilisation of the complete two-CPU node on a 0-100% scale; denominator differs from container CPU.
Cgroup memorymemory.usage_in_bytes.Total monitor cgroup memory charge.
RSStotal_rss from memory.stat.Resident memory charged to the monitor cgroup.
P95Nearest-rank 95th percentile of workload-window samples for each run; averaged across runs.Descriptive high-use observation, not uncertainty or a confidence interval.
Attribution boundary. Monitor-cgroup CPU measures user-space processing and kernel time charged to monitor tasks. eBPF programs execute in the context of observed tasks, so this is not total eBPF, application, node or system overhead.

3. Protocol and Workload Window

  1. Require explicit approval of a corrected calibration before the official campaign.
  2. Rotate profiles by round: F/U/N, U/N/F, N/F/U.
  3. Apply the profile, recreate the relevant monitor Pod when present and capture before-state.
  4. Start a nominal 75-second sampler and wait ten seconds before the exploit.
  5. Record host-side workload start/end nanoseconds around one 1,793-worker exploit invocation.
  6. Keep only samples whose timestamps fall within that workload interval.
  7. Capture alert completeness, losses and restart delta independently of the numeric metrics.
  8. Wait a ten-second cooldown before the next profile; do not retry failed runs.

The 75-second setting is the sampling horizon, not the workload duration. Duration comes from the trigger's run-end record. The sampler validates numeric CPU fields and divides by measured elapsed time rather than assuming exact one-second intervals.
